Problem Description  
你每個月存 10000 元到銀行中，銀行的每月利率為 0.1% ，以複利計算，請問 3 個月後，你的帳戶為多少錢？  
底下的表格示範了如何得到第 3 個月時，帳戶中的本利和（本金 + 利率總合）。  

| 月份 | 月初金額 | 月底本利和 | 備註 |
|---|---|---|---|
| 第一個月 | 10000 | 10010 | 月初存入 10000 元。<br>利息為 10000 * 0.1% = 10<br>所以本利和為 10010 |
| 第二個月 | 20010 | 20030.01 | 第二個月再存入 10000<br>加上前一個月的 10010<br>所以月初有 20010 元 |
| 第三個月 | 30030.01 | 30060.04001 | 所以第 3 個月時，本利和為 30060.04001 元。 |

我們定義底下幾個符號：  
r: 每期利率。以前例而言， r = 0.1%  
n: 期數。以前例而言， n = 3  
p: 每期投入金額。以前例而言 p = 10000  
現在，給你前述的三個值（即 r, n 及 p ），請計算期末的本利和。以前例而言，期未的本利合為 30060.04001 元。  
Input File Format  
輸入有 3 行。第一行為 r ，為浮點數值。第二行為 n ，為一整數。第三行為 p ，為一整數。  
Output Format  
輸出本利和，請將數值以「整數」表示（無條件捨去）  
Example  

| Sample Input: | Sample Output: |
|---|---|
| 0.001<br>3<br>10000 | 30060 |

> 💡 **筆記**  
>
> 假設：  
> - r = 1.001（代表 1 + 0.001，即 0.1% 利率）  
> - n = 3（代表 3 期）  
> - p = 10000（每期投入 10000 元）  
> - ans = 0.0（初始金額）  
> long double儲存更精確的小數計算，輸出⇒無條件捨去(long long) ans 直接把 double 轉換成 long long，只保留整數部分  

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    long double r, n, p; //long儲存更精確的小數計算
    while(cin >> r >> n >> p){
        double ans = 0.0; //初始化0.0
        r += 1.0; //r= 1 + r，表示 (1 + r) 的成長
        for(int i = 0; i < n; ++i){
            ans = (ans + p) * r;  // 累積利息與本金
        }
        cout << (long long)ans << endl; // 轉換為整數（無條件捨去）
    }
    return 0;
}
```cpp

這個程式碼是一個用來計算複利的小程式，讓使用者輸入本金、年數和年利率，然後計算出指定年數後的本利和。讓我們逐行解釋這個程式碼的功能和邏輯。  

### 🔹 迴圈步驟解析

迴圈計算累積總和for(int i = 0; i < n; ++i)代表：  
1. 第 1 期：存 p 元，乘以 (1 + r)ans=(0+p)×r  
ans=(0+p)×rans = (0 + p) \times r  
1. 第 2 期：加入新存款 p，再乘 (1 + r)ans=(ans+p)×r  
ans=(ans+p)×rans = (ans + p) \times r  
1. 第 3 期：再存 p，再乘 (1 + r)ans=(ans+p)×r  
ans=(ans+p)×rans = (ans + p) \times r  
🔹 這個過程模擬「每期存款加上之前的累積資金，然後計算利息」。  

| 期數 i | 計算 (ans + p) * r | ans 更新後的值 |
|---|---|---|
| i = 0 | (0 + 10000) * 1.001 | 10010.000 |
| i = 1 | (10010.000 + 10000) * 1.001 | 20020.010 |
| i = 2 | (20020.010 + 10000) * 1.001 | 30060.04001 |
