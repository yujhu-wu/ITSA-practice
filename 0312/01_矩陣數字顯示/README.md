# 題目 1. 矩陣數字顯示

> ITSA 基礎題練習 · 第 0312 輪 · [回到本輪目錄](../README.md)

**程式碼檔案：** [solution.cpp](solution.cpp)

---

問題描述  
現有一可顯示四位數字的 LED 燈一組，可根據輸入的四位數字顯示數字。比如說，  
由鍵盤輸入 1234 ，則可在螢幕上顯示  
![題目圖片1](images/img1.png)  
若輸入 0789 ，則顯示  
![題目圖片2](images/img2.png)  
輸入格式  
輸入格式為 四個整數。  
輸出格式  
輸出值為輸入值的矩陣數字。  

> 💡 **筆記**  
>
> i表示一個數字的行數  
> k表示有4個數字  
> j表示一個數字的一行有5個*  

```cpp
#include <iostream>

using namespace std;

int main()
{
    int n = 0;
    string num[10][5][5] = {{{"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", "*"}, {"*", " ", " ", " ", "*"},{"*", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}},
    {{" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}},
    {{"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", " "}, {"*", "*", "*", "*", "*"}},
    {{"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}},
    {{"*", " ", " ", " ", "*"}, {"*", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}},
    {{"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", " "}, {"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}},
    {{" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}},
    {{"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}},
    {{"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}},
    {{"*", "*", "*", "*", "*"}, {"*", " ", " ", " ", "*"}, {"*", "*", "*", "*", "*"}, {" ", " ", " ", " ", "*"}, {" ", " ", " ", " ", "*"}}};

    while (cin >> n)
    {
        for(int i = 0; i < 5; i++) //將每個數字固定由上排到下排執行
        {
            int output = n;
            int w = 1000;
            for(int k = 0; k < 4; k++)//解析數字的每一位（千、百、十、個位）
            {
                int number = 0;
                number = output / w;//1234=>1
                output %= w;//剩234
                w /= 10;//往百位數、十位、個位
                for(int j = 0; j < 5; j++)//一行中的每一個字
                {
                    cout << num[number][i][j];//輸出該數字的行字=>1
                }
                if(k != 3) cout << " ";//不是第四個數字後面都輸出空格
            }
            cout << endl;//k四個循環(數字)跑完後要下一行
        }
    }
    return 0;
}
