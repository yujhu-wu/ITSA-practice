Problem Description  
你每個月存10000元到銀行中，銀行的每月利率為0.1%，以複利計算，請問3個月後，你的帳戶為多少錢？  
底下的表格示範了如何得到第3個月時，帳戶中的本利和(本金 +利率總合)。  

| 月份 | 月初金額 | 月底本利和 | 備註 |
|---|---|---|---|
| 第一個月 | 10000 | 10010 | 月初存入10000元。<br>利息為10000 * 0.1% = 10<br>所以本利和為10010 |
| 第二個月 | 20010 | 20030.01 | 第二個月再存入10000<br>加上前一個月的10010<br>所以月初有20010元 |
| 第三個月 | 30030.01 | 30060.04001 | 所以第3個月時，本利和為30060.04001元。 |

我們定義底下幾個符號：  
r: 每期利率。以前例而言，r = 0.1%  
n: 期數。以前例而言，n = 3  
p: 每期投入金額。以前例而言p = 10000  
現在，給你前述的三個值(即r, n及p )，請計算期末的本利和。以前例而言，期未的本利合為30060.04001元。  
Input File Format  
輸入有3行。第一行為r，為浮點數值。第二行為n，為一整數。第三行為p，為一整數。  
Output Format  
輸出本利和，請將數值以「整數」表示(無條件捨去)  
Example  

| Sample Input: | Sample Output: |
|---|---|
| 0.001<br>3<br>10000 | 30060 |

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    long double r, n, p;
    while(cin >> r >> n >> p){
        double ans = 0.0;
        r += 1.0;
        for(int i = 0; i < n; ++i){
            ans = (ans + p) * r;
        }
        cout << (long long)ans << endl;
    }
    return 0;
}
```cpp

這個程式碼是一個用來計算複利的小程式，讓使用者輸入本金、年數和年利率，然後計算出指定年數後的本利和。讓我們逐行解釋這個程式碼的功能和邏輯。  
接下來是函數m的實現：  
1. int s=p,pm[30],pt[30],rr=floor(r*1000);：聲明了四個變量。s是用來保存原始的本金，pm[30]和pt[30]是兩個長度為30的整型數組，rr是利率乘以1000後向下取整的結果。  
1. for(int i=0;i<30;i++)：初始化pm和pt數組中的元素，pm的前11個元素設置為0，pt的所有元素設置為0。  
1. for(int k=0;k<n;k++)：外層迴圈，遍歷每一年的計算。  
1. for(int i=0;i<30;i++)：對pt數組進行乘法計算，計算結果保存在pt中。  
1. for(int i=0;i<30;i++)：對pt數組進行進位處理。  
1. for(int i=3;i<30;i++)：將pt數組中的元素向前移動3位。  
1. for(int i=0;i<30;i++)：對pt數組進行加法計算。  
1. for(int i=0;i<30;i++)：對pt數組進行進位處理。  
1. if(k==n-1)：判斷是否到達指定的年數。  
1. for(int i=29;i>=11;i--)：從高位到低位遍歷pt數組，找到第一個非零值並輸出之後的值。  
1. else：如果沒有到達指定的年數，則進行下一年的計算。  
1. pt[11]+=s;：將原始本金加到pt數組的第12位上。  
1. for(int i=0;i<30;i++)：將pt數組的值複製到pm數組中，然後將pt數組中的值全部設置為0。  
總的來說，這個程式碼實現了複利計算的功能，通過迴圈和數組操作，計算了指定年數後的本利和。
